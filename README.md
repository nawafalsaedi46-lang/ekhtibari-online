# اختباري - نظام متعدد المعلمين

هذه النسخة تجعل كل معلم مستقلًا عن الآخر.

## المزايا
- دخول المعلم برقم ترخيص + كلمة مرور.
- كل اختبار مربوط بمعرف المعلم داخل السيرفر.
- المعلم لا يستطيع طلب اختبار معلم آخر حتى لو عرف رقم الاختبار.
- لوحة Admin لإنشاء التراخيص وإيقافها وتفعيلها وتغيير كلمات المرور.
- حفظ عدة اختبارات داخل حساب كل معلم.
- تصميم وطباعة A4 الموجودان في مشروع اختباري.

## التشغيل على Windows

افتح PowerShell داخل مجلد المشروع:

```powershell
npm install
Copy-Item .env.example .env
notepad .env
npm start
```

ثم افتح:

- دخول المعلمين: http://localhost:3000
- الإدارة: http://localhost:3000/admin-login

## بيانات الإدارة الافتراضية قبل تعديل .env

اسم المستخدم:
admin

كلمة المرور:
ChangeMe123!

غيّرها قبل البيع أو النشر.

## إنشاء معلم

1. ادخل لوحة الإدارة.
2. اكتب اسم المعلم وكلمة المرور.
3. اضغط "إنشاء الترخيص".
4. سيظهر رقم مثل:
   EK-1234-5678
5. أعط المعلم رقم الترخيص وكلمة المرور.

## مهم للنشر التجاري

هذه النسخة تستخدم ملف JSON على السيرفر للحفظ، وهي مناسبة للاختبار والتجربة والبداية.
عند تشغيل الموقع لعدد كبير من المعلمين على الإنترنت، انقل التخزين إلى PostgreSQL أو Supabase مع قاعدة بيانات دائمة.
العزل الأمني موجود من جهة السيرفر: كل عمليات الاختبارات تأخذ teacherId من جلسة الدخول، وليس من المستخدم.

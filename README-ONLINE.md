# اختباري - النسخة الأونلاين متعددة المعلمين

هذه النسخة جاهزة للنشر على استضافة Node.js مع PostgreSQL.

## لماذا هذه النسخة؟
النسخة المحلية كانت تحفظ المعلمين والاختبارات في ملف JSON.
هذا مناسب للتجربة على جهازك، لكنه غير مناسب للبيع لعدة معلمين على الإنترنت.

هذه النسخة تحفظ:
- المعلمين
- أرقام التراخيص
- كلمات المرور المشفرة
- الاختبارات
- جلسات تسجيل الدخول

داخل PostgreSQL.

## العزل
كل طلب فتح/تعديل/حذف اختبار يستخدم `teacher_id` من جلسة تسجيل الدخول على السيرفر.
المعلم لا يرسل teacher_id بنفسه، لذلك لا يستطيع الوصول لاختبارات معلم آخر.

## متغيرات البيئة المطلوبة
- DATABASE_URL
- SESSION_SECRET
- ADMIN_USERNAME
- ADMIN_PASSWORD
- NODE_ENV=production

## أمر التشغيل
npm start

## النشر
يمكن نشر المشروع على خدمة Node.js مثل Render أو Railway، وربطه بقاعدة PostgreSQL.

بعد النشر:
- `/` دخول المعلمين
- `/admin-login` دخول الإدارة
- `/teacher` لوحة المعلم
- `/admin` لوحة الإدارة
